# zen plugin

Canonical plugin home for the `zen` theme.

## Ownership

- zen-owned widgets and rendering surfaces
- zen-specific artifact presentation
- zen-owned current state, strict validation, and release V1 persistence seams
- zen visual/runtime integration with theme core contracts
- zen-owned sound pack cue/scene descriptors for app sound runtime
