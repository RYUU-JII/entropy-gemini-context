현재 페이지에서만 남는 반응

피드와 숏폼의 좋아요와 댓글은 열린 페이지의 메모리에서만 처리합니다. 계정이나 서버로 전송하지 않으며, 새로고침하거나 페이지를 닫으면 사라집니다. 다른 방문자에게 보이는 누적 반응이 아닙니다.

분석과 추적

방문자 분석 SDK, 광고 추적기, 쿠키, 브라우저 저장소를 사용하지 않습니다. 스크롤 위치는 화면 효과를 조절하는 데만 사용하며 감정이나 주의 상태를 판정하지 않습니다. 글꼴과 작품, 영상은 이 사이트에 포함된 파일과 코드로 제공하며 외부 이미지·글꼴·영상 서비스에 요청하지 않습니다.

공유와 외부 링크

공유 버튼은 선택한 게시물의 링크를 클립보드에 복사하거나 기기의 공유 창을 엽니다. 사용자가 선택한 공유 대상에는 해당 링크가 전달됩니다. GitHub 또는 Chrome Web Store로 이동하면 해당 서비스의 데이터 처리 방침이 적용됩니다.

웹사이트 제공 과정

사이트를 제공하는 호스팅 사업자는 페이지 요청에 필요한 IP 주소, 요청 시각 등의 접속 기록을 처리할 수 있습니다. 이 시제품에는 별도의 참여 서버가 없습니다. 서버에 반응을 저장하는 기능을 도입하면 저장 항목, 목적과 삭제 방법을 먼저 이 안내에 반영합니다.

브라우저 확장과의 구분

이 피드는 확장의 사용 기록이나 보호 설정에 접근하지 않습니다. Entropy 확장의 설정, 사용 기록과 분석 결과는 사용자의 기기에서 처리·보관되며 외부로 자동 전송되지 않습니다. 확장의 자세한 기록 선택, 삭제와 암호화 범위는 프로젝트의 개인정보처리방침에서 확인할 수 있습니다.
