ENTROPY / PRIVACY

Privacy Policy

Settings, usage records, and analysis results are processed and stored on your device. Entropy does not automatically send these records to external services.

Data handled by the extension

Entropy uses settings, protected-site rules, goals, schedules, and protection outcomes to apply the protection you choose. Small security records protect local keys and sensitive actions.

If you choose to keep usage records, they include site domains, usage time, visits, sessions, and protection outcomes. Optional activity history on protected sites summarizes tab movement, scrolling, feed use, and media activity to help you understand your usage.

Protection features inspect page structure as needed to apply filters and other effects. Raw page text, typed text, and input contents are not saved as usage or activity-history records. Site icons use the browser's local icon cache or image data already available on your device.

Browser history and bookmarks are accessed for cleanup, preview, or backup only when you request the related feature and grant its browser permission. Tab grouping and notifications also request permission when you enable them.

Consent and control

Choose records for protected sites only, basic records across all sites, or no records before recording begins. You can change the scope, select activity-history categories, exclude sites, or turn recording off in Settings. Protection may still observe a protected page as needed to work when recording is off.

Turning recording off stops new usage records without deleting existing ones. Settings lets you delete analytics separately or reset all Entropy settings and data. Removing the extension also removes its browser-managed local storage under normal Chrome behavior.

Storage and protection

Stored data supports site protection, usage feedback, and the features you choose. Daily usage facts have a rolling 90-day retention window; summaries and intervention records have separate retention periods.

You can start without a password. By default, log keys are stored in your local browser profile, so a copy of that profile can expose them. Optional data locking protects the detailed-log encryption key with a passphrase. Site settings, aggregate statistics and protection keys remain readable in the profile. Site protection and aggregate statistics continue while locked. New detailed logs are saved only after you unlock; missing detail from the locked period is not reconstructed. The passphrase cannot be recovered.

Backups and exports

Full backups are encrypted with a separate backup passphrase. Activity-history exports can contain readable browsing-derived records. Keep backup passphrases safe and review exported records before sharing.

Exports are created on your device and are not automatically uploaded. You decide whether to keep a file or share it. Support can access records only if you explicitly provide a file or diagnostic material.

Sharing and advertising

Entropy does not sell user data or use it for advertising. It does not automatically share extension records with third parties.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Website visit

This website does not include visitor analytics. Its web host may process ordinary request logs, such as IP addresses, to serve the site. Those logs are separate from extension records.

설정과 사용 기록, 분석 결과는 이 기기에서 처리·보관되며 외부로 자동 전송되지 않습니다. 기록을 시작하기 전에 보호 사이트만, 모든 사이트의 기본 기록, 기록하지 않음 중에서 선택합니다. 기본 기록에는 도메인, 이용 시간, 방문·세션 횟수가 포함되며, 보호 사이트에서는 선택한 탭 이동·스크롤·피드·미디어 이용의 집계 기록도 남길 수 있습니다.

설정에서 기록 범위와 활동 이력을 바꾸거나, 사이트를 제외하거나, 기록을 끌 수 있습니다. 기록을 꺼도 보호 기능에 필요한 페이지 관측은 이어질 수 있습니다. 저장된 분석 데이터는 별도로 삭제할 수 있고 전체 초기화도 가능합니다. 사이트 아이콘은 브라우저의 로컬 캐시나 이미 기기에 있는 이미지를 사용합니다.

암호 없이 바로 시작할 수 있습니다. 기본적으로 로그 키는 로컬 브라우저 프로필에 저장되므로 프로필을 복사한 사람에게 노출될 수 있습니다. 선택적인 데이터 잠금은 상세 로그의 암호화 키를 암호로 보호합니다. 사이트 설정, 집계 통계와 보호용 키는 암호화되지 않습니다. 잠긴 동안에도 사이트 보호와 집계 통계는 계속 동작합니다. 새 상세 로그는 잠금 해제 후부터 저장하며 잠긴 기간의 상세 로그를 소급해 만들지 않습니다. 잠금 암호는 복구할 수 없습니다. 전체 백업은 별도 암호로 암호화됩니다. 활동 이력 내보내기 파일에는 읽을 수 있는 사용 기록이 포함될 수 있습니다. 파일은 자동 업로드되지 않으며 공유 여부는 사용자가 결정합니다.

Entropy는 데이터를 판매하거나 광고에 사용하지 않습니다. 문의는 지원 안내를 이용해 주세요. 이 웹사이트의 호스팅 업체는 페이지 제공을 위해 IP 주소 등의 접속 로그를 처리할 수 있으며, 확장 프로그램의 기록과는 별개입니다.
