# Active Migrations

이 경로에는 아직 종료되지 않은 migration 문서만 둔다.

migration 문서는 반드시 다음을 포함해야 한다.

- 현재 상태
- 목표 상태
- exit criteria
- canonical successor

종료된 migration은 `docs/archive/legacy-plans/` 또는 `docs/archive/evidence/` 로 이동한다.
