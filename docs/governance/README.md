# Governance Docs

이 경로는 문서 운영 규칙과 전역 엔지니어링 가드레일을 모은다.

- `document-system.md`: 문서 분류, naming, archive 기준, 자동 점검 원칙
- `document-registry.md`: 현재 canonical docs map
- `agent-routing-index.md`: task/symptom에서 canonical 문서와 첫 조사 entrypoint로 가는 얇은 라우팅 표
- `fallback-elimination-policy.md`: fail-fast 구조 원칙과 fallback 금지/예외 기준
- `import-boundaries.md`: cross-module import guard
- `refactoring-playbook.md`: large refactor execution 기준
