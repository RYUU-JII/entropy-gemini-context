## Purpose

This document is the thin routing layer between an incoming task and the
canonical architecture docs. It selects the first place to investigate; it is
not a fix location and does not select the file to patch.

Use this index to reduce the first pass of search, then confirm the real owner
through the target document's owner table, canonical path, system flow, or
function ledger.

## Routing Rules

- Treat `Start here` as an investigation starting point, not a fix location.
- Do not patch the first code file just because it appears in this table.
- Confirm ownership inside the referenced `Active` document before editing.
- If the owner path crosses into another subsystem, follow the referenced
  companion document instead of forcing the original route.
- Treat `Common false starts` as files or seams that may be relevant for
  presentation or symptoms but are not the first source of truth.
- `Proposed`, `Draft`, and `Hold` documents are context only unless the user
  explicitly asks to adopt or evaluate that proposal.
