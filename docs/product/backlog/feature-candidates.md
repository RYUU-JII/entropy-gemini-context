# 추가 기능 후보

- Status: Hold
- Owner: product / nudge runtime
- Last validated against code: 2026-09-30
- Path policy: planning-allowed

## 문서 목적

현재 릴리스에서 보류한 기능 아이디어와 재검토 조건을 모은다.
후보 등록은 구현 착수나 출시 약속을 의미하지 않는다. 기존 기능의 완성도와
사용자가 이해하기 쉬운 제품 구성을 우선하며, 확장팩의 출시 여부·구성·일정은 미정이다.

## 영상 자동재생 차단 — 직접 선택한 콘텐츠만 재생

- 상태: `Hold`; 향후 확장팩 후보
- 등록일: 2026-09-30
- 목적: 사용자가 해당 영상의 재생을 명시적으로 선택하기 전까지 정지 상태를 유지해,
  페이지 진입이나 피드 탐색만으로 시청이 시작되는 상황에 개입한다.

### 기대 동작

- 새 영상은 재생 미허용 상태로 시작한다.
- 해당 영상의 재생 버튼 클릭이나 명시적인 키보드 재생 조작으로 허용한다.
  페이지의 다른 곳을 클릭한 사실만으로 전체 영상의 잠금을 풀지 않는다.
- 다음 콘텐츠로 바뀌면 다시 선택을 요구한다. 같은 영상 요소를 재사용하는
  플레이어에서도 이전 콘텐츠의 허용 상태가 다음 콘텐츠에 넘어가지 않아야 한다.

### 보류 이유와 확장 가능성

스킵 방지가 시청 중 반복적인 넘기기에 개입한다면, 이 기능은 시청 시작 시점의
의도 확인을 맡는다. 역할은 있지만 현재 핵심 기능으로 추가하기에는 체감 가치에 비해
설정·설명과 사이트별 유지보수 부담이 크다고 판단해 우선순위를 낮춘다.

향후 자동재생, 다음 영상 자동진입, 호버 미리보기 제어를
‘직접 선택한 콘텐츠만 재생’이라는 기능군으로 묶는 방향을 검토할 수 있다.
이 묶음과 확장팩 구성은 후보이며 개별 기능의 구현 범위는 아직 확정하지 않는다.

### 재검토 조건

- 사용자가 자동재생 때문에 원치 않는 시청을 시작한다는 불편이 반복적으로 확인된다.
- 기존 보호 기능의 완성도가 확보되고, 추가 설정의 가치가 명확해진다.
- 지원할 사이트·플레이어와 iframe 권한 범위, 명시적 재생 조작의 판별 방식이 정리된다.
- 지원 범위에서 차단 신뢰성과 유지보수 비용이 제품 가치에 비해 적절한지 확인한다.

### 구현 검토 메모

재검토 시 [비디오·미디어 소유권 문서](../../architecture/repository/friction-nudge-effect-boundary-map.md)를
기준으로 현재 owner를 다시 확인한다. 영상 발견은 기존 `VideoElementObserver`를 활용하고,
재생 허용 정책은 별도 가드가 맡아 `VideoManager`의 기능 수명주기에 연결하는 방향을 검토한다.
기존 `PageMediaHold`의 정지 제어 기반을 참고하되 의식·게이트의 미디어 정지 정책과
충돌하지 않아야 한다.

`autoplay` 속성 제거만으로 사이트의 스크립트 재생을 막을 수는 없다.
재생 이벤트 이후 정지시키는 방식은 첫 프레임·소리가 전혀 나오지 않는다는 보장을 주지 않는다.
초기 차단 시점과 페이지 실행 영역의 재생 호출 제한 필요성을 함께 검토하고,
권한 없는 iframe이나 특수 플레이어까지 모든 사이트에서 완전 차단을 약속하지 않는다.
